# WhatDoUC

This the code repository of the WhatDoUC Project. The project consists of several sub components, which are available under separate repositories. 

The easiest way to get the whole project is cloning the [whatdouc-root](https://github.com/whatdouc-uni-aalen/whatdouc-root) repository with sub links.
